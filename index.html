Native OS boundary

A browser page cannot silently change system power settings, install applications, enumerate unrestricted folders, manage operating-system processes, or run arbitrary shell commands. Use a trusted native companion application or managed enterprise integration for those functions, with explicit user authorization.

Component registry

Technology integration catalogue

Every requested technology is accounted for in the architecture. Runtime ownership is isolated; not every library is loaded or initialized on this page.

Primary interactive layer

Alpine.js owns local state for this prototype. HTMX is reserved for server-rendered hypermedia requests. Datastar is an alternative reactive layer, not an additional owner for the same DOM subtree.
